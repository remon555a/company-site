# スカイライン・テクノロジーズ 企業サイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ株式会社」のコーポレートサイトです。HTML と CSS のみで構成された、1ページ完結の静的サイトです。

> ※ 本サイトは架空の企業のサンプルです。実在の団体・人物とは関係ありません。

## サイトの概要

Web・モバイル・AI・クラウドを横断して開発を行う企業、という設定のサイトです。ページ内には次のセクションがあります。

| セクション | 内容 |
| --- | --- |
| NEWS | お知らせ（サービス開始、イベント登壇、採用情報） |
| ヒーロー | キャッチコピーと相談ボタン |
| 実績数値 | プロジェクト数、人員数、リピート率、創業年 |
| 事業内容 | Web / モバイル / AI・データ活用 / クラウド・インフラ |
| 強み | 選ばれる理由 4点 |
| 開発実績 | 事例 3件（架空） |
| 会社概要 | 会社名、設立、所在地などの情報テーブル |
| お問い合わせ | 相談フォーム（デモのため実際には送信されません） |

### 特徴

- 外部ライブラリや画像ファイルを使わず、`index.html` 1ファイルで完結
- スマートフォン表示に対応したレスポンシブデザイン
- `prefers-reduced-motion` に配慮したアニメーション設定

## ブラウザで index.html を開く手順

ビルドやサーバーの準備は不要です。

### 方法1: ファイルをダブルクリックする

1. このリポジトリのフォルダ（`company-site`）を Finder などで開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザでサイトが表示されます。

### 方法2: ブラウザにドラッグ＆ドロップする

1. ブラウザ（Chrome、Safari、Firefox、Edge など）を起動します。
2. `index.html` をブラウザのウィンドウにドラッグ＆ドロップします。

### 方法3: ターミナルから開く（macOS）

```sh
cd company-site
open index.html
```

## ファイル構成

```
company-site/
```
